# 파크리오마당

파크리오 주민을 위한 비공식 홈페이지입니다. `node preview-server.cjs`를 실행한 뒤 `http://127.0.0.1:4173`에서 미리 볼 수 있습니다.

## 현재 구현

- 주민 제공 원본 이미지 `assets/파크리오 문주 사진(1).png`를 메인 대표 이미지로 사용
- 공지사항 → 자유로운 이야기 → 안건제안 → 자료실 메뉴를 모바일 화면에서도 상단에 표시
- 자료실의 법 / 규약과 규정 / 기타 분류, 파일 첨부와 웹 링크 등록 (현재 브라우저에만 저장)
- 주민 제공 이미지 `assets/파크리오 로고 사진.png`를 상단 제목·메뉴 뒤의 은은한 배경으로 사용
- 별지 제7호서식 기반 안건 작성 화면: 제목, 제출자, 의결주문, 제안이유, 주요내용, 비용추계서, 참고사항(근거규정/기타), 첨부파일
- 의안번호·의결일·의결사항을 운영자 관리 항목으로 구분
- 관리규약 제37조 안내 및 안건 내용의 브라우저 임시저장 (첨부파일 제외)
- 안건 작성 후 `js-parkrio@naver.com`으로 보내는 메일 초안 열기. 방문자가 메일 앱에서 직접 보내야 발송되며 첨부파일도 직접 추가해야 함
- 기존 파크리오마당 Supabase 프로젝트와 연결: 이메일 가입·로그인·비밀번호 재설정, 회원 전용 이야기·댓글, 공개/회원 공지, 내 정보 수정, 운영자 공지·회원 이용 제한 화면
- 운영 주체와 문의처는 `config.js`에 ‘미정’으로 기록. 운영자 계정도 아직 지정되지 않음

## 운영 전 설정과 확인

구체적인 확인 항목은 `운영 전 설정.md`에 정리했습니다.

Supabase 데이터 구조는 기존 프로젝트를 활용합니다. 이메일 확인 설정과 인증 메일 수신, 비밀번호 재설정, 일반 회원과 운영자 권한은 실제 시험 계정으로 검증해야 합니다. 운영자 이메일이 정해지면 Supabase Auth의 **app_metadata.site_role = admin** 으로 관리자 권한을 지정해야 합니다. 일반 회원이 자신의 권한을 바꾸도록 허용하면 안 됩니다.

`config.js`의 운영 주체와 문의처를 확정하고 개인정보 안내(수집 항목·목적·보관/삭제 기준·담당 연락처)를 완성한 뒤 공개해야 합니다. 실제 운영 전 전용 SMTP와 인증 후 돌아올 배포 주소도 Supabase Auth에 설정합니다. 현재 자료실 파일·링크는 IndexedDB에 저장되어 같은 브라우저에서만 보입니다. 안건제안은 메일 앱의 초안을 열 뿐 자동 전송이나 공식 접수가 아닙니다. GitHub 저장소는 `435parkrio/parkrio-madang`으로 비공개 생성했습니다. 공개 배포는 아직 하지 않았습니다.

## 설정 파일

`config.js`에는 Supabase의 공개 가능한 publishable key만 넣습니다. secret/service-role 키는 넣지 않습니다. 운영 주체·문의처는 같은 파일의 `operatorName`, `contactEmail`에서 나중에 바꿀 수 있습니다. 외부 라이브러리 버전은 HTML의 CDN 주소에 고정했습니다.
